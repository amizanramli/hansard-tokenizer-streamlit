# Sample data

This folder is intentionally empty in the repo (see `.gitignore`) — Hansard
transcript workbooks aren't bundled here.

To try the app, drop any Hansard `.xlsx` file with a `Transcript` sheet and a
`Speech Text` column into this folder and upload it through the app's
**Upload & tokenize Hansard files** tab, or point the uploader at files from
your own `Hansard Excel 2` directory.
